## Versão Longa (Post no LinkedIn — Opcional)

**Over the years, I realized how much time developers lose configuring local environments.**

My Local Place started as a simple setup guide and evolved into a local infrastructure platform focused on developer experience, observability and reproducibility.

**The problem:** Setting up local environments is repetitive, error-prone and time-consuming. Each project requires different services, and managing these manually leads to inconsistent environments.

**The solution:** A modular Docker-based platform that centralizes infrastructure tools (PostgreSQL, Redis, Kafka, Ollama, etc.) into a single, observable environment. It provides an operational dashboard to manage containers, monitor resources and inspect logs.

**It's not about Docker itself** — it's about reducing friction so developers can focus on building software.

The platform is used daily for backend development, data pipelines, AI experiments and workflow automation. It has **92.28% test coverage** and follows modern practices with TypeScript, FastAPI and component-based architecture.

This project demonstrates:
- Platform thinking — solving problems that benefit multiple projects
- Developer experience focus — prioritizing developer productivity
- Pragmatic engineering — balancing simplicity with functionality

**Takeaway:** Sometimes the best projects come from solving real problems you face every day.

🔗 [GitHub Repository](https://github.com/LucasBiason/my-local-place)

## Versão Técnica (Experiência no LinkedIn)

**My Local Place — Local Infrastructure Platform**

Personal platform engineering project focused on improving developer experience in local environments.

**Objective:**
Reduce environment setup time and improve reproducibility by centralizing infrastructure tools into a single, observable Docker-based platform.

**Responsibilities:**
- Designed and implemented modular service architecture with Docker Compose
- Built FastAPI backend for container orchestration and monitoring
- Developed React dashboard for operational visibility (resource usage, logs, lifecycle management)
- Implemented health checks and resource monitoring for all services
- Maintained 92.28% test coverage with 69 automated tests

**Key Achievements:**
- Reduced environment setup time from hours to minutes
- Enabled consistent environments across machines and developers
- Created extensible platform architecture for adding new services
- Improved developer productivity through operational dashboard

**Technologies:** Docker, Docker Compose, Python, FastAPI, React, TypeScript, Pydantic

**Status:** In active use for backend development, data pipelines, AI experiments and workflow automation.
